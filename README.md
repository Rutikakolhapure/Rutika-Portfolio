# Rutika Tarachand Kolhapure - Software Engineer Portfolio

World-class, production-ready, visually stunning personal portfolio designed for Senior Software Engineers, Cloud Developers, and DevOps Engineers.

## Tech Stack
- **HTML5**: Semantic, accessible markup (WCAG AA compliant, ARIA labels).
- **CSS3**: Handcrafted modular CSS (Variables, Flexbox, Grid, Glassmorphism, Keyframe Animations, Dark Palette).
- **Vanilla JavaScript**: Pure JS ES6+ (Particle Engine, Interactive Architecture Diagram Inspector, Typing Effect, Intersection Observer Counters & Skill Bars, Dynamic Modals, Toast Notification System, Contact Form Validation).

## Key Features
1. **Animated Loading Screen**: Custom animated RK circular SVG loader with smooth fade-out effect.
2. **Sticky Glassmorphism Navbar**: Transparent on top, blurred glass on scroll, section active highlights, and mobile responsive drawer.
3. **Hero Section**:
   - Interactive Canvas Particle Mesh background.
   - Profile illustration frame with rotating glowing rings and floating tech badges (Python, Django, AWS, Docker).
   - Typing effect cycling through backend & cloud engineering roles.
4. **About Me**: Engineering bio and dynamic animated counters (9.1 CGPA, 5+ Projects, 2+ Hackathons, 140+ DSA Problems).
5. **What I Build**: 4 SaaS-style service cards covering Backend Engineering, Cloud Infrastructure, DevOps Automation, and Artificial Intelligence.
6. **Skills Matrix**: Filterable categories with animated percentage progress bars.
7. **Production Projects**:
   - **AWS Cost Optimization System** (Featured Project with interactive architecture pipeline).
   - **HireFlow** (AI-Powered Talent Assessment Platform).
   - **CloudScale** (High Availability Multi-AZ AWS Infrastructure).
   - **NeuroScope-AI** (Parkinson's Disease Multi-Modal Detection Engine).
   - **Agro-Optics** (AI Agricultural Decision Support).
8. **Interactive Architecture Showcase**: Dynamic node switcher for AWS Cost Optimizer, CloudScale VPC, NeuroScope ML, and HireFlow Trust Engine.
9. **Experience Timeline**: Career milestones tracking achievements from 2025 to 2026.
10. **Achievements & Certifications**: Grid featuring hackathons, NPTEL awards, IEEE membership, and AWS/Docker certificates.
11. **GitHub Statistics**: Contribution heatmaps, pull requests, stars, and language focus indicators.
12. **Contact & Footer**: Interactive contact form with real-time feedback, status notifications, social channels, and smooth back-to-top button.
